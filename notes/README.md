# 学习笔记

每周交付一份整合笔记：问题、原理、源码证据、实验结果和结论。课程页保留任务与验收；笔记记录你的回答，不再分别维护读书/源码/实验三份重复材料。

- [第一周笔记](weeks/w01.md)已经备好，所有结果保持待填写。
- 后续使用 [每周模板](../templates/weekly-note.md) 创建 `weeks/wNN.md`。
- 稳定、跨周的知识可逐步提炼到 `concepts/`，论文摘要到 `papers/`，定位过程到 `debugging/`；有实际内容时再建文件。
- 阶段结束把关键结论汇总到 [reports](../reports/README.md)。

原始 trace 和数据库放在 `artifacts/wNN/`。笔记只摘录支撑判断的少量片段，包含文件名、行号或时间范围。没有拿到证据时写“待验证”，不要把预期结果当成实测。
